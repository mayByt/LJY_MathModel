# 建模报告

根据题目动态调整问题数量。

本赛题共 4 个子问题。

## 1. 总体建模框架

### 1.1 研究主线

本题不是四个彼此独立的小题，而是一条从数据到能力的递进链：

```text
题面与附件核验
  -> A 组质量信号清洗与冲突诊断
  -> 样本质量 Q、领域质量 q 与 17 域配比 p 的 Loss 响应面
  -> B 组经典标度律与质量/配比效率修正
  -> 算力预算下 N、D、Q、p 联合配置
  -> C 组 Benchmark 能力、规模效应与技术效应分解
  -> Loss-Benchmark 桥接、前沿预测与不确定性传播
```

所有拟合、验证和外推数据按“真实观测、半合成、插值、外推/估算”分层。半合成或外推数据只用于扩充检验和敏感性分析，不与真实观测等权混合。

### 1.3 总体评价原则

1. **拟合优度不代替外部验证。** A4/A5 和 B1 用于拟合，A6–A11、B2/B3、B4/B5 用于验证，A12–A15 与 B9/B10 只讨论外推。
2. **组成数据使用组成模型。** 17 个配比不能作为 17 个独立自变量直接解释，采用 Scheffé 混料模型及“从域 j 向域 i 转移质量”的方向导数。
3. **时间数据不随机划分。** 问题四采用滚动起点回测，所有标准化和模型选择只在当期训练窗完成。
4. **所有不确定性逐级传播。** 质量评分、配比模型、标度律、优化和 Loss–Benchmark 桥接均保存 bootstrap 样本或协方差，最终预测区间不得只包含最后一层回归误差。

## 2. 假设敏感性预检

### 模糊表述及解释

#### 2.1 “22 个质量指标”的列表字段如何处理

- 解释 A：把每个列表元素展开，得到 25 个以上标量维度。
- 解释 B：题面按字段计为 22 个指标，每个列表字段先压缩为一个标量。

采用解释 B 作为主口径，以满足题面对 22 维指标的明确表述；将展开 QuRating 四分量得到的 25 维口径作为敏感性方案。二分类 logits 转成正类概率，六级 logits 转成 0–5 等级的 softmax 期望，QuRating 四分量先分别稳健秩变换再取均值。官方数据卡建议使用 argmax，本报告将 argmax 作为对照，因为期望分值保留了分类不确定性且对微小 logit 波动更平滑。

#### 2.2 结构性指标是否都应单调处理

- 解释 A：所有自然语言统计量都强行指定单调正向或负向。
- 解释 B：教育价值、流畅度、广告和重复率等可单调处理；长度、句数、数字比例和平均词长存在“过短/过长均差”或领域依赖，应采用饱和型或适中型效用函数。

采用解释 B。否则 GitHub、数学和论文域会因为数字、符号、长文档天然较多而被系统性低估。所有转换后的效用值仍统一为越高越好。

#### 2.3 质量冲突的含义

- 解释 A：任意两个指标排序不一致即为冲突。
- 解释 B：不同语义块对同一文本给出实质上相反的高低判断才算冲突。

采用解释 B。相关系数不高不等于样本冲突；冲突必须发生在同一文本上，并同时满足域内极端性和块间差异阈值。

#### 2.4 A、B 附件能否直接合并

- 解释 A：二者都使用交叉熵 Loss，可以直接拼接后拟合一个公式。
- 解释 B：验证集、模型族和实验设计不同，只共享方向性和结构，需使用数据源校准项或分阶段估计。

采用解释 B。直接拼接会把验证集难度、模型族、数据配方和半合成生成口径差异误当成参数量、数据量或质量效应。主方案先在 B1 拟合经典标度律；质量函数只在 B6/B7 的同一 `(N,D)` 单元内利用 `Q` 对照识别；A 组只提供配比相对效应与质量基线。B7 完整包含 B6，二者不得作为训练/验证两份独立证据。B8 的 `Q_score` 与 Loss 方向和题意相反，主估计不使用；只有在明确标注“方向反转敏感性”时才检验 `1-Q_score` 口径。跨来源比较使用仿射校准、相对残差或秩指标，不把校准项解释为科学机制。

#### 2.5 问题三中配比是否必须随预算联合变化

- 解释 A：把 17 个配比分量与 `N,D,Q` 一次性放入非线性优化。
- 解释 B：题设说明调整配比不增加总算力；若广义模型中配比效应与成本及质量无不可识别交互，则最优配比可先解析地取问题一的 `p*`，随后只优化 `N,D,Q`。

采用解释 B，但按问题二最终门禁进一步收紧：主方案固定训练中心 `p_ref`，不再给出联合优化 `p` 的正式结果。A 组没有同一配比下同时改变质量处理强度的实验，问题二又得到 `JOINT_P_READY=false`；强行让配比随预算变化会制造数据不支持的结构转移。问题三仍输出 `D_i=p_ref_i D`，因此领域资源分配没有被遗漏。

#### 2.6 “开源模型”的筛选口径

- 解释 A：只要模型页面可访问就算开源。
- 解释 B：主口径要求权重可获得，并记录许可证是否允许研究复现；严格口径进一步仅保留 unrestricted 权重。

采用解释 B。主分析保留 `Open model weights?=Yes` 的语言模型，许可证限制作为分层变量；严格敏感性分析只保留 unrestricted 权重。排行榜 `Type` 继续区分 pretrained、continuously pretrained、chat/finetuned 和 merge。

#### 2.7 “未来 12/24 个月”的起点

- 解释 A：从论文撰写日期起算。
- 解释 B：从模型使用数据的最后观测日期起算。

采用解释 B。排行榜最后提交日期为 2025-03-13，因此主预测时点为 2026-03 与 2027-03 附近；若代码阶段更新数据，起点自动改为更新后的最大观测日期。

### 快速验算与递进性检查

1. A4–A15 的配比表与对应 Loss 表索引全部匹配；配比行和与 1 的最大偏差为 0.004，可归一化后使用。
2. 按实际 ID 核验，A1 的 1,419 条 arXiv 和 10,000 条 GitHub 记录分别全部包含在 A2、A3 中；扩展集剩余记录数分别为 16,104 和 193,752。A1 与 A2/A3 不是独立样本，代表性检验必须比较 A1 子集与扩展集余集。
3. A4 的 8,704 个配比分量中有 3,928 个为 0，比例约 45.13%。因此 CLR/ILR 需要大量伪计数且结果可能对伪计数敏感，主模型优先使用能自然处理零配比的 Scheffé 混料模型。
4. 1M 与 60M 检验表使用完全相同的 256 组配比。13 个验证域的跨规模 Loss 排序 Spearman 相关中位数为 0.9944，范围约 0.9801–0.9980，说明配比效应在 1M 到 60M 间高度稳定。
5. 1B 的 64 组配比并不是 1M/60M 的同索引配比，不能按 index 跨文件直接对齐；它应作为独立跨规模检验集。
6. 在仅用于选型的快速试验中，线性混料岭回归在 1B 检验集的 13 域排序相关中位数约为 0.7019；加入两两交互的二阶 Scheffé 模型约为 0.8314，因此二阶交互具有明显边际价值。
7. B1 的 8 个参数规模内，数据量与验证 Loss 的 Spearman 相关均为 -1，经典标度律的单调方向与数据一致。
8. C6 扩展桥接表中 Loss 与综合得分的总体 Spearman 相关约为 -0.5491；高可比 7 条约为 -0.6071。关系方向合理但噪声较大，不能把桥接误差忽略。
9. 注意力与基础训练开销相等时 `eta*N*D*Lctx=6*N*D`，故 `Lctx_crit=6/eta=30000`。C7 虽有多处架构字段错误，但上下文五类值可独立核验；32768 和 131072 越过临界值，后续按外生情景分析。
10. 问题三固定 `p_ref` 后，`N,D,Q_A` 仍随预算、质量成本函数和上下文情景变化；17 域 Token 为 `D_i=p_ref_iD`，问题三新增条件仍有显著边际效果，递进关系成立。
11. B7 的 450 条记录完整包含 B6 的 360 条且共享点的 Loss 完全相同，因此 B6/B7 只能视为同一半合成实验的基础版与扩展版；正式质量模型以 B7 为唯一主表并按 `(N,D)` 成块交叉验证。
12. B8 在固定 `(N,D)` 下 `Q_score` 与 Loss 的组内 Spearman 中位数约为 `+0.993`，而 B6/B7 约为 `-0.95`；B8 另有大量 Loss 被截在 `0.5`。这与“Q 越高质量越好、Loss 越低”的题意冲突，必须隔离。
13. 问题一训练配比中心的加权质量约为 `0.538956`，参考近优配比约为 `0.545368`，差异很小；而质量与配比边际收益的 Spearman 仅 `-0.1434`。因此 `Q(p)=p^Tq` 只描述组成带来的基线质量，不能代替配比覆盖与交互效应。

### 最终采用的解释

- 质量主口径为 22 个字段压缩后的标量效用；25 维展开、argmax 和不同权重作为敏感性方案。
- 质量冲突按语义块定义，综合质量采用冲突自适应的稳健 M 估计，同时保留冲突指数而不把冲突信息隐藏。
- 五个语义块作为主分层；Rule-based、DSIR、Model-based 三种信号来源作为第二套审计分层，用来检查某一来源是否系统性支配总分。
- 配比主模型采用二阶 Scheffé 混料回归；线性混料模型和树模型只作基线或鲁棒性对照。
- 广义标度律先比较有效样本量、加性质量惩罚和质量改变指数三类候选，再以分组留出性能和可识别性选择最简模型；配比效应与静态质量分开进入模型。
- 问题三主方案固定 `p=p_ref`、`lambda_0=0` 后优化 `N,D,Q_A`；问题二 `JOINT_P_READY=false`，因此不再把联合 `p` 优化列为正式敏感性。
- 问题四以提交日期作为主时间轴，以显式开放权重证据为主口径；官方六项 Average 为主综合能力，0.90 分位动力学前沿分解规模相关贡献与非规模残余技术贡献。

### 4.2 计算可行性

- 质量数据流式处理复杂度约为 `O(n*m)`，其中 `n≈27.25 万`、`m=22`；按 5,000–20,000 条分块时内存为 `O(batch*m)`。
- 二阶混料特征数为 153，512 条训练样本下 Ridge 的直接线性代数规模可控；5 折交叉验证和 500 次 bootstrap 可按验证域并行。
- 标度律只有少量全局参数，50 个多起点的稳健非线性最小二乘在 CPU 上可行；每次目标计算为 `O(n_B)`。
- 主资源优化只有 `log N,log D,Q` 三个连续变量；即便按 60 个预算、5 个上下文长度、3 个成本函数和 30 个初值计算，也属于低维可并行问题。
- C8 约 0.23 GB，逐文件解析和在线聚合为 `O(total JSON bytes)`，无需将全部 JSON 同时载入内存。
- 所有随机过程固定主种子 2026；bootstrap 子任务用可复现的派生种子，并在结果文件中记录。

## 5. 问题一模型

本节在方法首次出现处使用 `[P1-Rx]` 标记可引用的原始论文；标记只说明基础方法或数据指标的来源。本方案中的“五语义块等权、稳定性修正、冲突阈值、支持域约束”等均为针对本题数据结构的二次设计，不归因于原论文。完整书目信息和“可引用内容边界”见 5.8。

### 5.1 质量指标标量化与同向化

对 logits 向量 `a=(a_0,...,a_{K-1})`，先做数值稳定 softmax：

```math
pi_l = exp(a_l-max(a)) / sum_r exp(a_r-max(a)).
```

- `ad_en=[has_ad,no_ad]`：`z=P(no_ad)=pi_1`。
- `fluency_en=[not_fluent,fluent]`：`z=P(fluent)=pi_1`。
- 四个 PRRC 六级 logits：`z=sum_{l=0}^5 l*pi_l/5`；PRRC 四维质量定义来自 Meta-rater `[P1-R1]`。
- `fineweb_edu`：取唯一元素，再作稳健经验分位变换。
- `qurater`：四个分量分别作稳健分位变换后等权平均；25 维敏感性方案保留四分量。其写作风格、专业知识、事实/知识和教育价值四维语义依据 QuRating `[P1-R2]`。
- DSIR 三项为对高质量域的重要性对数分值，数值越大（越不负）越好，使用正向经验分位变换；重要性重采样的数据选择思想见 `[P1-R3]`。

先构造不重复计数的质量参考宇宙：A1 中除 arXiv/GitHub 外的 5 域，加上 A2/A3 全量，共 261,086 条。为避免 GitHub 的样本量主导变换，指标参考分布采用七域等权经验分布 `F_ref(x)=7^(-1) sum_d F_d(x)`，其 0.5% 与 99.5% 分位作为 winsorize 边界。对明确正向指标使用 `T+(x)=F_ref(x)`，明确负向指标使用 `T-(x)=1-F_ref(x)`。结构型指标使用锚点适中函数：先选 `no_ad>0.8`、`fluency>0.8`、`cleanliness>=0.8` 的高可信文本，估计其对数中位数 `m_j` 与 MAD `s_j`，再定义

```math
Tmid(x)=exp(-(log(x+eps)-m_j)^2/(2*s_j^2)).
```

22 个字段按以下口径处理：

| 语义块 | 字段 | 方向/变换 |
| --- | --- | --- |
| 教育与领域价值 | fineweb_edu、qurater、dsir_books、dsir_wiki、dsir_math | 正向 |
| 表达与整洁 | fluency_en、modernbert_readability、modernbert_cleanliness、terminal punctuation | 前三项正向；终止标点正向但做域内敏感性 |
| 推理与信息 | modernbert_reasoning、modernbert_professionalism、unigram entropy、unique words | 正向至锚点上限，极端值截尾 |
| 噪声与重复 | ad_en、no-alphabet fraction、top-2gram、top-3gram、uppercase fraction、numerical fraction | no-ad 正向；其余负向；数字比例在数学/GitHub 域改用适中型 |
| 结构充分性 | word count、sentence count、mean word length | 适中型/饱和型 |

整向量 NaN 不进行伪造性 softmax。主方案在块内忽略该字段并重新归一权重；域中位数插补只用于敏感性比较。

### 5.2 客观权重与稳健综合质量

为避免 22 个相关指标重复计权，五个语义块先各自评分，再等权合成。块内使用稳定性修正的 CRITIC 权重；原始 CRITIC 以指标变异性和指标间冲突性赋客观权重 `[P1-R4]`，下式中的 bootstrap 稳定项 `r_j` 是本方案新增：

```math
c_j = sd(z_j) * sum_{k in block(j)} (1-|rho_jk|),
r_j = 1/(1+CV_boot(median_d(z_j))),
w_{j|b} = c_j*r_j / sum_{k in b} c_k*r_k.
```

其中 `rho` 使用 Spearman 相关，`r_j` 惩罚 bootstrap 下域中位数不稳定的指标。块得分为

```math
B_ib = sum_{j in b} w_{j|b} z_ij.
```

五块默认等权 `W_b=0.2`，从而不会因某一类指标数量较多而占据优势。对照方案包括字段等权、熵权、25 维展开和数据卡给出的 Meta-rater 权重。

另按产生机制把指标标记为 Rule-based、DSIR、Model-based 三种来源，计算三类来源对最终 Q 的贡献率和来源间相关性。该三来源结构只作审计与敏感性方案，不作为主权重层：若三类直接等权，仅含 3 个指标的 DSIR 会获得与 8 个模型信号、11 个规则信号相同的总权重，且不利于解释“高价值但高噪声”这类跨来源、跨语义冲突。

### 5.3 冲突定义与消解

样本冲突指数定义为

```math
K_i = max_b B_ib - min_b B_ib.
```

若 `K_i` 超过本域 90% 分位，并且同时存在 `B_ib>=0.75` 与 `B_ic<=0.25`，则定义为显著冲突。另记录产生最大差异的块对，形成“价值高但噪声高”“专业性高但可读性低”“结构自然但教育价值低”等冲突类型。

为保留指标级连续信息，再定义辅助质量冲突指数。令 `m_i` 为 22 个同向化指标的加权中位数，则

```math
QCI_i = sum_j w_j*|z_ij-m_i|.
```

并记录强冲突指示 `I_i=1{max_j z_ij>0.8 and min_j z_ij<0.2}`。`K_i` 是主冲突定义，避免高度相关的同类指标重复计数；`QCI_i` 和 `I_i` 用于绘制域级冲突率、识别具体冲突指标和验证结论是否依赖块划分。

无冲突时使用等块加权平均。有冲突时使用 Huber M 估计 `[P1-R5]`：

```math
Q_i = argmin_{q in [0,1]} sum_b W_b * rho_1.345((B_ib-q)/s_b),
```

其中 `s_b` 为块内域稳健尺度。采用 IRLS 求解，初值为加权中位数，最大 50 次，`|q^(t+1)-q^t|<1e-8` 停止。输出不仅包含 `Q_i`，还保留 `K_i` 和冲突类型，防止稳健平均掩盖真实矛盾。

作为冲突消解敏感性方案，比较样本级指数可靠度 `a_ij=exp(-lambda*|z_ij-m_i|)`，其中 `lambda` 在 `[0,5]` 网格变化。该方案不作为主模型，因为较大的 `lambda` 可能把真实但少数的质量维度误当成异常意见；Huber M 估计具有有界影响且调节常数含义更稳定。

### 5.4 样本到领域的聚合及扩展集对照

领域质量使用 Huber 均值或 10% 截尾均值：

```math
q_d = HuberMean({Q_i: domain(i)=d}).
```

每个领域进行 500 次分层 bootstrap `[P1-R6]`，报告 95% 区间。由于 A1 的 arXiv/GitHub ID 全部包含在 A2/A3 中，不能做独立两样本检验。代表性检查比较 `A1_d` 与 `A_ext,d \ A1_d`，报告质量均值/中位数差、Wasserstein 距离、KS 统计量和分层 bootstrap 区间；全域质量则用 A2/A3 全量估计。若余集与 A1 差异显著，后续以扩展集全量值为主，A1 仅用于含正文的冲突成因分析。

### 5.5 17 域质量映射

对 A16 的 direct/near_direct 域先使用确定映射。对 inferred 域，分别从 A1 正文和 A18 文本流式提取：对数长度、行数、字母/数字/大写/标点/空白比例、URL 比例、代码符号比例、词汇丰富度和重复 n-gram 代理等特征。以各域特征分布间的标准化 Wasserstein 距离与对角 Mahalanobis 距离构成

```math
d_dg = 0.5*d_Wasserstein(d,g)+0.5*d_Mahalanobis(d,g),
pi_dg = exp(-d_dg/tau)/sum_h exp(-d_dh/tau),
q_d = sum_g pi_dg*q_g.
```

温度 `tau` 通过 leave-one-known-domain-out 选择；对 inferred 域向全局均值做经验贝叶斯收缩，收缩强度由 A18 域样本量和最近邻距离决定。bootstrap 同时重采样文本和质量记录，传播映射不确定性。

### 5.6 二阶 Scheffé 领域配比模型

配比先闭合：`p_i <- max(p_i,0)/sum_j p_j`。组成数据受单纯形约束、适合用对数比坐标分析的理论依据见 Aitchison `[P1-R7]`；但 A4 中零配比分量约占 45.13%，因此不把需要伪计数的 CLR/ILR 作为主模型，只在多个伪计数水平下将其作为敏感性基线。主模型采用 Scheffé 混料响应面 `[P1-R8]`，对每个验证域 `k=1,...,13` 拟合：

```math
L_k(p)=sum_i beta_ik*p_i + sum_{i<j} beta_ijk*p_i*p_j + epsilon_k.
```

由于 `sum p_i=1`，模型不另加截距。二阶特征共 `17+C(17,2)=153` 个，使用 Ridge `[P1-R9]` / Elastic Net `[P1-R10]` 正则化，正则参数由 A4/A5 内部 5 折交叉验证选择。主结果采用二阶 Ridge 保证稳定，稀疏 Elastic Net 用于筛选可解释交互；线性 Scheffé 为结构基线，Random Forest `[P1-R11]`、XGBoost `[P1-R12]` 或 ExtraTrees `[P1-R14]` 作为 RegMix-style 非线性预测对照。利用大量小模型配比实验训练回归器、再把优选配比迁移到更大模型的总体思路来自 RegMix `[P1-R13]`。黑箱模型只比较预测能力，不用其特征重要性替代 Scheffé 的领域协同解释。

领域 i 的影响不能用普通偏导解释，而应使用从领域 j 向 i 转移一个微小份额的方向导数：

```math
ME_{i<-j,k}(p) = dL_k(p+delta(e_i-e_j))/d(delta)|_{delta=0}.
```

`ME<0` 表示从 j 调配到 i 可降低验证域 k 的 Loss。交互项 `beta_ijk<0` 表示 i、j 在该验证域上具有互补效应，`>0` 表示共同投入产生冗余或替代。

综合配比目标为

```math
J(p)=sum_k v_k * (Lhat_k(p)-median_train(L_k))/IQR_train(L_k),
```

主口径 `v_k=1/13`，并用原始 Loss 等权平均作敏感性对照。最优配比

```math
p* = argmin J(p)
s.t. p_i>=0, sum_i p_i=1,
     p_i <= u_0.99,i,
     dist_support(p)<=r_0.99.
```

最后两个约束把解限制在训练配比支持域附近，防止优化器利用模型外推漏洞。采用多起点 SLSQP 或投影梯度，至少 30 个 Dirichlet 初值；目标相对改进小于 `1e-9` 或 2,000 次迭代停止。

注意：`q(p)=p^T q` 本身是 p 的线性组合，与 Scheffé 一阶项共线。A 组没有独立改变质量处理强度的实验，因此不能把 `q(p)` 作为独立变量并宣称识别了质量因果效应。问题一只用它解释最优配比的质量构成；质量效应由问题二的 B6–B8 识别。

为回答“高质量域是否真的带来更优配比收益”，计算域质量 `q_i` 与平均方向边际效应 `ME_i` 的 Spearman/Kendall 相关，并用问题一 bootstrap 同时传播二者误差。该分析只解释关联，不把相关关系表述为质量的独立因果效应。

### 6.3 阶段一：经典标度律

使用 B1 拟合 Chinchilla 型基线：

```math
L_0(N,D)=E+A n^{-\alpha}+B d^{-\beta},
\qquad n=N/10^9,\ d=D/10^9.
```

约束

```math
E,A,B,\alpha,\beta>0.
```

估计采用按模型规模等总权重的加权 Huber 非线性最小二乘。Huber尺度只能由当前训练折残差的MAD确定。参数在对数空间优化，以 50 个真实拉丁超立方初值运行；当梯度无穷范数小于 `1e-8`、相对目标改进小于 `1e-10` 或达到 5,000 次函数评估时停止。B1 的 `run_id` 在当前附件中逐行唯一，不能作为相关簇；置信区间必须按8个模型规模做簇 bootstrap，不能逐行独立重采样。

簇 bootstrap 有放回抽取8个规模。某一规模被抽中多次时，每次出现必须赋予独立的抽样实例ID，或使用等价的簇乘数权重；不得在加权函数中重新按原始 `N_params_B` 合并而抵消重复次数。每个抽中实例总权重为 `1/8`，输出抽样索引、重复次数、有效簇数和失败原因。

预注册三个基线候选：

```math
M_0: L=E+A n^{-\alpha}+B d^{-\beta},
```

```math
M_C: L=E_C+K_C(6ND)^{-\zeta},
```

```math
M_{ND}: L=E+A n^{-\alpha}+B d^{-\beta}
      +G(n d)^{-\xi}.
```

主模型选择顺序为：留一模型规模误差、AICc、残差随 `\log N,\log D` 的结构、参数稳定性。若复杂模型没有超过一个标准误差的验证优势，选择更简单的 `M_0`。训练早期可能受 warm-up 和优化瞬态影响，主口径保留全部 B1；另以只在训练折内选择的最小 Token 阈值做敏感性，禁止根据验证集删点。

### 6.4 A/B 两套质量尺度的连接

问题一的质量分和 B7 的 `Q_score` 都位于 `[0,1]` 且定义为越大越好，但没有同一语料在两套系统中的配对观测，故“数值相同”只能作为传递假设。

定义问题一给定配比的基线质量

```math
Q_{base}(p,q)=\sum_{d=1}^{17}p_d q_d.
```

训练配比中心和参考近优配比的点估计分别约为

```math
Q_{base}(p_{ref})=0.538956,
\qquad
Q_{base}(p^*)=0.545368.
```

两者接近，且 `q_d` 与领域边际收益弱相关，因此 `Q_{base}` 不能替代配比响应。问题三中的 `Q` 定义为“经过质量投入后的总体有效质量”，并满足

```math
Q\ge Q_{base}(p,q).
```

主口径采用身份连接 `Q_B^*=Q_A`。为传播不可识别的尺度差异，另使用参考点固定的斜率映射：

```math
Q_B^*
=\operatorname{clip}\left[
Q_{ref}+s_Q(Q_A-Q_{ref}),\ \varepsilon,\ 1
\right],
\qquad s_Q\in\{0.5,1,1.5\},
```

其中 `Q_ref=Q_base(p_ref)`，`s_Q=1` 为主情景。该映射只是敏感性校准，不得解释为已经由数据估计的物理换算。

### 6.5 阶段二：质量函数候选与选择

B7 是半合成完整因子网格，正式模型只使用 B7 的 450 个唯一点。B6 不再单独参与拟合或验证。质量模型按以下四类预注册；第四类双通道模型只作为候选挑战模型，不能因机制解释更丰富而绕过统一交叉验证直接成为主模型。

#### 6.5.1 有效样本量模型

依据质量感知标度律，令高质量数据提高有效样本数：

```math
G_{Q,1}:
L(N,D,Q)
=E+A n^{-\alpha}
+\frac{B}{d^{\beta}Q^{\gamma}},
\qquad \gamma\ge 0.
```

其等价有效 Token 数为

```math
D_{eff}=D Q^{\gamma/\beta}.
```

当 `Q=1` 时退化为经典模型。这里的 `Q=1` 是 B7 半合成实验的归一化上锚点，不宣称真实 Pythia 语料“完美无噪声”。

#### 6.5.2 加性质量惩罚模型

```math
G_{Q,2}:
L(N,D,Q)
=L_0(N,D)+c_Q(1-Q)^{\nu_Q},
\qquad c_Q,\nu_Q\ge0.
```

该模型允许半合成数据通过近似固定的 Loss 位移表达质量下降。它仍满足 `Q=1` 时退化为经典模型，并保证质量提高不使 Loss 变差。

#### 6.5.3 质量改变标度系数或指数

最新大规模质量干预实验表明，过滤、去重和重写可能改变标度系数与指数，因此设置受约束扩展：

```math
G_{Q,3}:
L(N,D,Q)
=E+A n^{-\alpha}
+B\exp[b_Q(1-Q)]d^{-[\beta+\beta_1(1-Q)]}.
```

该形式在 `Q=1` 时系数乘子恢复为1、数据指数恢复为经典 `beta`，因而严格退化为 `L0`。要求在 B7 支持域内 `\partial L/\partial Q\le0` 且 `\beta+\beta_1(1-Q)>0`。任何用于实现的参考点必须随拟合参数冻结保存，不能在预测时根据验证批次的 Q 中位数重新定义。只有当分组留出 RMSE 明显下降、参数符号在至少 80% bootstrap 中稳定且没有违反单调性时，才保留 `G_{Q,3}`；否则回退到 `G_{Q,1}` 或 `G_{Q,2}`。

#### 6.5.4 双通道质量作用模型

为检验质量是否同时提高模型参数利用效率和数据利用效率，增加双通道有效资源候选：

```math
G_{Q,4}:
L(N,D,Q)
=E+A(nQ^{\gamma_N})^{-\alpha}
+B(dQ^{\gamma_D})^{-\beta},
\qquad \gamma_N,\gamma_D\ge0.
```

其中 `N_eff=NQ^{\gamma_N}`、`D_eff=DQ^{\gamma_D}`。当 `Q=1` 时模型严格退化为经典标度律；当 `\gamma_N=0` 时，它退化为只通过数据通道起作用的嵌套形式。为降低 `\alpha\gamma_N`、`\beta\gamma_D` 与经典指数之间的混淆，主轨道固定 B1 经典参数，仅估计 `\gamma_N,\gamma_D`；敏感性轨道才允许经典参数在 B1 bootstrap 区间内联合 profile。

`G_{Q,4}` 必须与前三类模型使用完全相同的 B7 成块交叉验证、损失指标和一个标准误差规则。只有当它相对更简单的嵌套模型具有超过一个标准误差的验证优势，且两个质量参数的 profile/bootstrap 区间有限、不触及搜索边界、符号在至少 80% bootstrap 中稳定并通过全支持域单调性检查时，才可升级为主模型。若 `\gamma_N` 弱识别或区间包含 0，则回退到 `G_{Q,1}`；若两个通道均弱识别，则只保留探索性结果。

质量模型不采用随机逐行切分，而采用四种成块验证：

1. 留一 N 水平；
2. 留一 D 水平；
3. 留一 `(N,D)` 单元；
4. 留一 Q 水平，分别检查内插和端点外推。

每个折只用训练行拟合绝对残差 `r=L-L0(N,D)`，验证集预测固定为 `Lhat=L0_hat+DeltaLQ_hat`。正式绝对 RMSE、MAE 和 nRMSE 不得读取验证单元的真实 `Q=1` Loss。同单元 `L(Q)-L(1)` 只作为辅助配对效应指标；留出 `Q=1` 时该辅助指标记为 `not_applicable`，不能以零误差计入选模。

四类切分不能按全部折直接平均，否则45个留一单元折会占主导。对每个模型先在每类切分内求平均，再令四类切分等权形成主评分：

```math
S_m=\frac14\sum_{t\in\{N,D,cell,Q\}}
\frac1{K_t}\sum_{k=1}^{K_t}RMSE_{m,t,k}.
```

按分层配对 bootstrap 估计 `S_m` 的标准误，再用“一个标准误差规则”选择最简可用模型。`G_{Q,3}` 和 `G_{Q,4}` 都属于复杂候选，不能仅凭解释性优先于交叉验证表现更好的简单模型。B8 不参与模型选择；把 `Q'=1-Q_score` 后的 B8 结果只列为异常敏感性，且 calibrated/extrapolated 分开报告。

### 6.6 阶段三：配比效应及其跨规模迁移

定义 `p_ref` 为 A4 训练配比闭合后的中心配比，而不是不确定性较大的 `p^*`。用问题一的综合 Loss 响应定义

```math
R(p)
=\frac{J(p)-J(p_{ref})}
{\operatorname{IQR}_{A4}[J(p)]},
\qquad R(p_{ref})=0.
```

`R(p)<0` 表示比训练中心更优，`R(p)>0` 表示更差。这样不会因 `p^*` 位于支持域边界、bootstrap 区间较宽而把一个不稳定点误当成绝对零点。

若质量主模型为有效样本量型，定义配比倍率

```math
\phi_p(N,p)
=\exp[-\kappa_p(N)R(p)],
```

```math
\kappa_p(N)
=\kappa_0(N/N_0)^{\delta_p},
\qquad \kappa_0\ge0.
```

其中 `N_0=10^6`。A6/A8 使用完全相同的 256 组配比，可估计配比幅度从 1M 到 60M 的变化；A10/A11 的 1B 独立配比只用于外部验证。若 `\delta_p` 的 profile 区间包含较宽的正负值，则冻结 `\delta_p=0`，只保留已由问题一验证的排序迁移，并对 `\kappa_0` 做情景网格。

若质量主模型为加性惩罚型，主接口保留当前透明的加性配比情景：

```math
L=L_0(N,D)+\Delta_Q(N,D,h_{s_Q}(Q_A))
  +\lambda_0(N/N_0)^{\delta_p}R(p).
```

其中 `lambda_0` 仍是预注册情景而非附件直接识别值。由于 A 组和 B 组没有绝对 Loss 单位配对，非零 `lambda_0` 不进入问题三主优化；问题三主基线固定 `p=p_ref` 或 `lambda_0=0`，从而严格退化到经典—质量模型。

乘性下界形式只作为敏感性候选。令 `L_B=L_0+Delta_Q`、`S=L_B-E`，可比较：

```math
L=E+S\exp\!\left[
\kappa_0(N/N_0)^{\delta_p}R(p)
\right],
\qquad \kappa_0\ge0.
```

该形式在 `p=p_ref` 或 `kappa_0=0` 时严格恢复经典—质量基线，并在 `S>0` 时保证 `L>E`。但它不能因为解释更漂亮就绕过同一套交叉验证和迁移验收直接成为主模型。任何方案都必须保留问题一的逐域上界和经验支持距离，A12–A15 只检查远尺度排序，不能反向调参。

修复后的迁移估计必须先在13个验证Loss域分别拟合标准化Loss对 `R(p)` 的稳健斜率，再汇总域级结果；A6/A8按相同配比index成对bootstrap，不能只对13域平均后的单一综合Loss拟合一个无区间斜率。每个A4/A5抽样还要固定问题一冻结的Ridge `alpha`，重新拟合153维Scheffé系数并重算 `J_b(p)` 与 `R_b(p)`；不得把同一系数矩阵复制500次充当bootstrap。

A组与B组没有绝对Loss单位配对，因此 `lambda_0/kappa_0` 均作为预注册情景/profile，而不报告伪精确点估计。问题三主基线固定 `p=p_ref`，使 `R(p_ref)=0`；联合配比优化只在通过物理性、迁移性和支持域门槛的强度情景下进行。若非零配比情景出现 `L<=E` 或迁移证据不足，则自动设置 `JOINT_P_READY=false`，但不阻断固定配比主接口。

### 6.7 最终广义标度律与可识别性边界

若 `G_{Q,1}` 获选，最终模型写为

```math
L_{eff}(N,D,Q_A,p;s_Q,\kappa_0,\delta_p)
=E+A n^{-\alpha}
+\frac{B}
{d^{\beta}h_{s_Q}(Q_A)^{\gamma}\phi_p(N,p)^{\beta}}.
```

当 `h_{s_Q}(Q_A)=1,p=p_{ref}` 时退化为经典标度律。更优配比允许 `\phi_p>1`，较差配比对应 `\phi_p<1`。

若 `G_{Q,2}` 获选，最终主情景写为

```math
L_{add}(N,D,Q_A,p;s_Q,\lambda_0,\delta_p)
=L_0(N,D)+c_Q[1-h_{s_Q}(Q_A)]^{\nu_Q}
 +\lambda_0(N/N_0)^{\delta_p}R(p).
```

同时输出乘性下界候选的敏感性结果，但只有其通过与加性情景相同的迁移、单调、支持域和折外误差检查时，才可作为联合 `p` 优化接口。

若 `G_{Q,4}` 获选，配比仍只作用于可由 A 组识别的数据通道：

```math
L_{dual}(N,D,Q_A,p;s_Q,\kappa_0,\delta_p)
=E+A[n h_{s_Q}(Q_A)^{\gamma_N}]^{-\alpha}
+B[d h_{s_Q}(Q_A)^{\gamma_D}\phi_p(N,p)]^{-\beta}.
```

`G_{Q,3}` 或 `G_{Q,4}` 仅在严格通过同一套成块验证、一个标准误差规则、单调性和参数稳定性检查时替换简单质量项。最终预测函数必须显式接收 `p`、`s_Q` 和配比强度情景，改变合法配比或映射情景时输出应按公式改变；不能只在 JSON 中登记这些字段而预测函数仍忽略它们。为保证问题三可优化，最终模型还必须通过支持域内连续、单调和下界检查。

本题数据不能可靠识别自由的 `Q\times p` 交互：A 组没有同一配比下改变质量处理强度的实验，B7 又没有配比变量。因此主模型不加入该交互。只在敏感性分析中加入有界项

```math
\Delta_{Qp}=\rho_{Qp}(Q_A-Q_{ref})R(p),
```

并令其最大绝对影响不超过主质量项与配比项绝对值之和的 20%。该结果不作为主要结论。

### 6.8 边际效用、弹性与替代条件

对有效样本量模型记

```math
T=\frac{B}{d^{\beta}h_{s_Q}(Q_A)^{\gamma}\phi_p^{\beta}}.
```

当 `\delta_p=0` 时，

```math
\frac{\partial L}{\partial N}
=-\frac{\alpha A}{10^9}n^{-\alpha-1},
```

```math
\frac{\partial L}{\partial D}
=-\frac{\beta T}{D},
\qquad
\frac{\partial L}{\partial Q_A}
=-\frac{\gamma T}{h_{s_Q}(Q_A)}h_{s_Q}'(Q_A).
```

若 `\delta_p\ne0`，须在 `\partial L/\partial N` 中补上 `\kappa_p(N)` 的链式项。对加性模型，

```math
\frac{\partial L}{\partial Q_A}
=-c_Q\nu_Q[1-h_{s_Q}(Q_A)]^{\nu_Q-1}h_{s_Q}'(Q_A),
\qquad
\nabla_p L=\lambda_p(N)\nabla_p R(p).
```

对双通道模型，记

```math
T_N=A[n h_{s_Q}(Q_A)^{\gamma_N}]^{-\alpha},
\qquad
T_D=B[d h_{s_Q}(Q_A)^{\gamma_D}\phi_p]^{-\beta},
```

则质量导数为

```math
\frac{\partial L}{\partial Q_A}
=-\frac{h_{s_Q}'(Q_A)}{h_{s_Q}(Q_A)}
\left(\alpha\gamma_NT_N+\beta\gamma_DT_D\right).
```

其质量—参数和质量—Token有限等价量统一使用数值根求解，不把两个通道强行压缩成单一解析倍数。

统一定义因素 `x` 的 Loss 降低弹性

```math
\epsilon_x
=-\frac{x}{L-E}\frac{\partial L}{\partial x}.
```

质量提高 `\Delta Q` 与参数扩张的局部等价关系为

```math
\Delta\log N_{equiv}
=\frac{(\partial L/\partial Q_A)\Delta Q_A}
{N(\partial L/\partial N)}.
```

两边导数都为负，因此质量提高对应正的等价参数增幅。有效样本量模型还给出质量与数据量的解析等价：

```math
\frac{D_2}{D_1}
=\left[\frac{h_{s_Q}(Q_{A,2})}{h_{s_Q}(Q_{A,1})}\right]^{\gamma/\beta}
\qquad
\text{（保持数据项与配比不变）}.
```

有限变化不使用一阶近似，而数值求解

```math
L(N(1+r_N),D,Q_A,p)
=L(N,D,Q_A+\Delta Q_A,p),
\qquad r_N\ge0.
```

同时求解等价 Token 增幅 `r_D`，并输出局部 `Delta log N_equiv`，不得保留整列空值。求根上界由当前情景允许的 B1/B7 观测域和 B9 扩展边界确定，不使用无约束的固定放大倍数。若根超出观测域但仍在 B9 边界内，标记为边界支持外推；超出 B9 时返回空值和明确状态码，不输出伪精确倍数。每条预测分别记录 N、D、Q、p 的支持状态。领域间替代或互补沿用问题一 Scheffé 方向导数和交互项，不由 `q_d` 排名推断。

### 6.9 参数估计、模型选择与验证

1. **经典参数：**B1 加权 Huber NLS；按8个模型规模簇 bootstrap 500 次，重复抽中的簇保留独立实例或乘数权重，不使用逐行唯一 `run_id`。
2. **质量参数：**固定或联合剖面经典参数，在 B7 上对绝对残差 `L-L0` 做成块交叉验证；正式预测不读取验证单元 `Q=1` Loss，配对差分只作辅助指标；B6 不重复计数。
3. **配比参数：**A4/A5 成对行 bootstrap 后固定 Ridge alpha 重拟合，A6/A8 的同配比跨规模变化按13域斜率和配比index成对 bootstrap 校准，A10/A11 独立验证；A12–A15 仅外推讨论。
4. **来源校准：**B2/B4/B5 只拟合 `L_{obs}^{(r)}=a_r+b_rL_{pred}+\epsilon_r` 的校准层，或报告族内中心化误差和秩相关；`a_r,b_r` 不进入问题三机制解释。
5. **残差诊断：**按 `\log N,\log D,Q` 检查偏差、异方差、尾部和自相关；报告 Huber 与普通最小二乘差异。
6. **单调性：**在支持域抽取 10,000 点，验证增加 `N,D,Q` 时 Loss 不增；配比方向只在经验支持域内解释。
7. **外推：**B9 定义大模型 `N,D` 边界；B10 是估算值，只比较数量级和排序。超出真实支持域后采用 profile/cluster bootstrap 区间并强制随外推距离不缩窄。
8. **模型选择：**四类成块切分先各自汇总、再等权形成主评分；优先完全折外的绝对 RMSE 和 MAE，其次辅助差分误差、AICc、参数稳定性和单调约束；采用一个标准误差规则选最简模型。
9. **流程门禁：**输入hash、数据硬门槛或泄漏测试任一FAIL时停止下游；最终run log写完后再生成manifest和输出hash。

问题二的成功标准不是单一训练集 `R^2`，而是：

- B1 留一规模预测稳定；
- B7 留一 `N,D,Q` 后，完全折外绝对预测仍保持质量方向和低误差，留出 `Q=1` 不出现结构性零误差；
- A6–A11 的配比排序迁移不低于问题一已验收水平；
- 三种 Q 尺度映射、inferred 域质量 bootstrap 和近优配比 bootstrap 下，质量—参数替代结论方向不翻转；
- 联合抽样中的质量参数、域映射和 Scheffé 系数不是点估计的机械复制；
- 所有结论清楚区分真实、半合成、插值和估算证据。

### 6.10 不确定性传播与问题三接口

每次外层 bootstrap 同时抽取并保存来源ID：

1. 问题一域质量与17域映射样本；
2. A4/A5 成对行后重新拟合的问题一 Scheffé 系数及有效近优配比样本；
3. B1 模型规模簇及重复抽样实例；
4. B7 的 `(N,D)` 单元簇及重新拟合的质量参数；
5. A6/A8 相同配比index的迁移抽样；
6. 分层平衡的 Q 尺度斜率情景 `s_Q in {0.5,1,1.5}`；
7. 弱识别的配比强度和 `delta_p` profile/情景。

每个样本重新计算 `Q_ref`、`R(p)`、`L(N,D,Q_A,p)`、弹性和等价参数/Token 倍数。问题三读取联合参数样本或情景，而不是只读取一个点估计，也不得将质量参数、Scheffé系数或 `s_Q` 的点值复制到全部抽样。有效联合抽样比例要求至少95%；低于80%为FAIL。

主输出接口为：

- `scaling_data_audit.json`：B1–B12 角色、重复、方向和截断检查；
- `classic_scaling_parameters.json` 与 `classic_scaling_bootstrap.csv`；
- `quality_model_comparison.csv`：四类质量律的成块验证；
- `generalized_scaling_parameters.json` 与 `generalized_scaling_bootstrap.csv`；
- `generalized_scaling_predictions.csv`；
- `elasticity_grid.csv`；
- `quality_parameter_equivalence.csv`；
- `units_contract.json`；
- `problem2_manifest.json`。

问题三的基线质量应写为 `Q_base(p,q)=p^Tq`。主方案若固定 `p`，使用该配比对应的 `Q_base`；联合优化 `p` 时，质量提升成本的起点必须随 `p` 更新，避免既从高质量域配比受益、又按旧低基线重复获得质量收益。第二轮验收分别输出 `CENTRAL_MODEL_READY`、`FIXED_P_READY`、`JOINT_P_READY` 和 `P12_FREEZE_READY`：固定配比主接口与联合配比扩展接口分别放行，不能再用单一 `INTERFACE_READY` 掩盖能力边界。

问题二的数据契约、异常处理、问题一接口、代码拆分、测试矩阵、验收阈值和失败降级规则见补充开发文档 [`PROBLEM2_DEVELOPMENT_PLAN.md`](./PROBLEM2_DEVELOPMENT_PLAN.md)；第一轮修复历史见 [`PROBLEM2_REPAIR_PLAN.md`](./PROBLEM2_REPAIR_PLAN.md)；V2 的乘性下界方案保留为敏感性背景；映射区间自洽、M01 综合 Spearman、单位合同、manifest 写后校验和版本化重跑以 [`PROBLEM2_REPAIR_PLAN_V3.md`](./PROBLEM2_REPAIR_PLAN_V3.md) 为最终执行规范。

最终封版再增加以下硬约束：问题一将 A4–A11 的配比响应、迁移验证数组和 Scheffé bootstrap 封装为 `problem2_bridge_input.npz`，问题二仅消费问题一冻结产物，不再直接读取附件 A；弹性同时报告标准总 Loss 口径 `-x/L*dL/dx` 与可约 Loss 口径 `-x/(L-E)*dL/dx`；任何非零配比情景出现 `L<E` 时均禁止联合优化 `p`；B1 删除 `D<2` B tokens 的 32 个早期检查点仅作敏感性，不反向调参。具体执行与验收以 [`PROBLEM2_FINAL_REPAIR_PLAN.md`](./PROBLEM2_FINAL_REPAIR_PLAN.md) 为问题二最后规范。

### 7.3 冻结 Loss、质量映射与三类成本

问题二最终中心模型为 M0+GQ2。令 $n=N/10^9$、$d=D/10^9$，主身份映射下

$$
L(N,D,Q_A)=
1.6897975629
+0.3539803207n^{-0.3399765819}
+1.2403055836d^{-0.2798781285}
+0.3620399283(1-Q_A)^{0.9902880683}.
$$

为传播 A/B 质量尺度不确定性，一般形式写为

$$
Q_{eff}=Q_0+s_Q(Q_A-Q_0),
$$

$$
L(N,D,Q_A)=
E+An^{-\alpha}+Bd^{-\beta}
+c_Q(1-Q_{eff})^{\nu_Q},
$$

其中 $Q_0=Q_{ref}=0.5389559588$，主场景 $s_Q=1$，敏感性 $s_Q\in\{0.5,1.5\}$。避免 clip 平台造成伪最优，数值上用

$$
Q_0\le Q_A\le
Q_{sat}=
\min\left(1,Q_0+\frac{1-\varepsilon-Q_0}{s_Q}\right),
\qquad \varepsilon=10^{-6}.
$$

题设三类成本保持原式：

$$
C_{train}=6ND,
$$

$$
C_Q=D[g(Q_A)-g(Q_0)]_+,
$$

$$
C_{attn}=\eta NDL_{ctx},
\qquad \eta=2\times10^{-4}.
$$

三种质量成本函数并列计算：

$$
g_{exp}(Q)=10^7e^{6Q},
\qquad
g_{pow}(Q)=5\times10^9Q^4,
\qquad
g_{log}(Q)=2\times10^9\ln(1+10Q).
$$

优化问题为

$$
\min_{N,D,Q_A}\ L(N,D,Q_A)
$$

$$
\text{s.t.}\quad
6ND+D[g(Q_A)-g(Q_0)]_+
+\eta NDL_{ctx}\le C,
$$

并满足预注册的 $N,D,Q_A$ 上下界。成本计算一律使用绝对参数数和绝对 Token 数；十亿单位只用于 Loss 公式和展示。

### 7.4 支持域、预算和外推标记

\qquad

$$

它取经典模型与质量模型共同覆盖范围。在低预算、超长上下文下可能不可行；此时报告 infeasible_under_strict_support，不人为放宽。

为完整回答题设的三档预算，主路径使用问题二声明的 operational extended 包络：

每个解按问题二支持信息标记 joint_observed、one_component_extrapolated、bridge_gap_extrapolated 或 boundary_supported_extrapolated。超出该包络的解无效。

### 7.5 解析消去 D 的二维优化

总成本可整理为

$$
C_{tot}
=D\left[(6+\eta L_{ctx})N+\Delta g(Q_A)\right],
\qquad
\Delta g(Q_A)=[g(Q_A)-g(Q_0)]_+.
$$

在固定 $(N,Q_A)$ 时，Loss 随 $D$ 单调下降，因此

$$
D^{max}(N,Q_A)
=
\frac{C}
{(6+\eta L_{ctx})N+\Delta g(Q_A)}.
$$

考虑边界：

$$
D^*(N,Q_A)
=
\min\{D_{max},D^{max}(N,Q_A)\},
\qquad
D^*\ge D_{min}.
$$

由此把三维约束优化降为 $(\log N,Q_A)$ 二维有界优化，减少病态尺度和局部最优风险。每个场景先做粗网格，再以最佳 20 个不同网格点进行 L-BFGS-B 或 trust-constr 局部精化；沿预算递增使用 continuation 热启动。

三档预算的全部 $3\times5\times3=45$ 个中心场景，再用完整三维 SLSQP/trust-constr 独立复核。二维与三维最优 Loss 相对差必须不超过 $10^{-6}$，并用加密网格保证最终值距网格最优不超过 $10^{-4}$。

在 $Q_A=Q_0$ 且边界未激活时，令

$$
\bar C=\frac{C}{(6+\eta L_{ctx})10^{18}},
$$

经典部分具有闭式基准：

$$
n^*=
\left(\frac{\alpha A}{\beta B}\right)^{1/(\alpha+\beta)}
\bar C^{\beta/(\alpha+\beta)},
\qquad
d^*=\frac{\bar C}{n^*}.
$$

它只用于初值和公式回归，不替代含质量投资的正式解。

### 7.6 KKT 解释和资源分配机制

内点且预算活跃时，三种资源的边际 Loss 降低/算力应相等：

$$
\frac{-L_N}{C_N}
=
\frac{-L_D}{C_D}
=
\frac{-L_Q}{C'_Q},
$$

其中

$$
C_N=(6+\eta L_{ctx})D,
$$

$$
C_D=(6+\eta L_{ctx})N+\Delta g(Q_A),
$$

$$
C'_Q=Dg'(Q_A).
$$

这组比值直接回答“下一单位算力应投给参数、数据还是质量”。若 $Q_A=Q_0$ 的下界乘子为正，说明当前预算下不值得启动质量投资；乘子降到零并离开下界时，才进入质量投资阶段。

### 7.7 结构性转移的数学定义

固定 $(g,L_{ctx},s_Q,support\_mode)$，定义最优活跃集合

$$
\mathcal A(C)=
\{Q=Q_0,\ Q=Q_{sat},\
N=N_{min/max},\
D=D_{min/max},\
C_{tot}=C\}.
$$

若预算临界点两侧满足

$$
\mathcal A(C^-)\ne\mathcal A(C^+),
$$

则定义为主要结构性转移。重点识别：

1. 质量投入由零变为正；
2. 质量达到饱和上界；
3. 参数或 Token 离开/到达支持边界；
4. strict_joint 由不可行转为可行。

对未改变活跃集合的平滑路径，再计算

$$
\theta_x(C)=\frac{d\log x^*}{d\log C},
\qquad
x\in\{N,D,Q_A-Q_0\}.
$$

若分段线性拟合相对单直线的 BIC 改善至少 10，且断点前后斜率差至少 0.15，则记为次要结构候选；0.10 和 0.20 作敏感性。候选区间用预算二分细化到 $\log_{10}C$ 宽度不超过 0.01。

旧版“成本份额相邻点 $L_1$ 跳变”不再作为主判据。原因是固定上下文时

$$
\frac{C_{attn}}{C_{train}}
=
\frac{\eta L_{ctx}}6,
$$

该比值与预算和最优 $N,D,Q$ 无关，不能证明预算诱发的结构转移。

### 7.8 上下文临界值及其正确解释

解析临界值为

$$
L_{ctx}^{crit}
=
\frac6\eta
=
30000.
$$

C7 的 32768 和 131072 位于临界值以上。五个场景下 $C_{attn}/C_{train}$ 分别约为 0.0683、0.1365、0.2731、1.0923 和 4.3691。

这个临界值表示上下文场景从“基础训练成本占优”转为“注意力代理成本占优”，不是预算方向上的结构转移。固定 $C$ 时，更长上下文收缩可行域，因此最优 Loss 理论上不能降低；若数值结果反向，优先检查单位、局部最优或约束实现。

6. C8 必须完成至少一项逐任务聚合。本方案同时重算 BBH 与 MATH hard，但只有达到预注册复现门槛的任务才进入正式证据；V2 中 BBH 通过、MATH 降级为敏感性。
7. C9 与 C1 核心内容等价，只做 hash/schema 核验，不重复加入样本；C10 只解释字段。

所有输出保留 `source_id`、`record_role`、`evidence_tier` 和 `duplicate_group`，确保同一模型、同一评测或同一桥接记录不会因多文件出现而重复计权。

### 8.3 开源口径、模型类型与时间轴

开源筛选分三级：

- 主口径 `open_weight_verified`：C2 或高置信 C1–C4 匹配明确给出 `Open model weights?=Yes`。限制性或非商业许可证可以进入，但单独标记，缺失许可证不自动解释为 unrestricted。
- 严格口径 `unrestricted`：权重开放，`Model accessibility` 为 `Open weights (unrestricted)`，并且许可证为允许研究和复现的明确许可证。
- 宽口径 `leaderboard_candidate`：C1/C2 排行榜内但开放权重证据缺失，仅作覆盖率敏感性，不能替代主结论。

模型类型固定为四层：pretrained 包含 pretrained 与 continuously pretrained；posttrained 包含 chat 和领域微调；merge 单独分析；multimodal/other 从主分析剔除。主贡献分解以 pretrained 层为确认性对象，因为训练算力、数据量和预训练 Loss 的含义在该层最一致。posttrained 单列“基础规模 + 后训练残余”结果；merge 因基座和训练成本难以归属，只作前沿对照。

主时间轴为 `Submission Date`，因为覆盖最完整且与排行榜观测对应。`Publication date` 只在高置信 C1–C4 匹配样本中做敏感性。预测起点固定为通过筛选的能力面板最大提交日期，而不是论文撰写日期；按当前数据应为 2025-03-13。C4 中晚于该起点的记录不得用于估计算力增长率或任何回测，防止未来信息泄漏。

### 8.4 实体匹配、重复记录和证据分层

模型名称先标准化组织前缀、大小写、分隔符、版本后缀、量化标记和 instruct/chat/base 标记，但不因名称相似就自动合并不同版本。C1 有 79 组重复 `Model` 字符串且没有完全重复行，处理规则为：

1. 同名称、同版本、同评测配置的重复提交保留最后一次有效提交，同时保存历史行；
2. 同名称但日期、参数量、类型或版本标记不同者保留独立 `model_version_id`；
3. C1/C4 精确规范名且参数量相对差不超过 5% 可自动匹配；
4. 模糊候选还须同时满足组织、模型族和版本一致，前沿点及全部训练算力匹配必须进入人工复核清单；
5. 一对多、多对一、参数冲突和类型冲突不得静默选择。

C4 训练算力证据分为 `reported`、`operation_counting`、`hardware_based`、`third_party_or_benchmark` 和 `missing`；主模型以前三层为主并在回归中使用证据权重，估算层作敏感性。由 `6ND` 推出的算力只能作为 `derived_compute` 敏感性，不能伪装为实测算力。

### 8.5 C8 逐任务聚合与综合能力

每个 C8 模型目录按时间戳选择最新可解析 JSON；若最新文件损坏则回退到同目录较早可解析文件并记录。四个已知截断文件必须进入损坏日志。BBH 必须按官方排行榜归一化口径：对每个子任务 $j$ 读取选项数对应的随机猜测下界 $l_j$，先计算

$$
z_{ij}=\max\left\{0,\frac{s_{ij}-l_j}{1-l_j}\right\},
\qquad
\widehat S_i^{BBH}=\frac{100}{|J_i|}\sum_{j\in J_i}z_{ij}.
$$

其中 BBH 提取各子任务的 `acc_norm,none`，归一化后对子任务等权平均，样本数只用于完整性审计。MATH hard 提取 7 个类别的 `exact_match,none`，仍按 `n-samples.effective` 重建整体 exact-match，缺失时才退回 `original`。V2 对 1,786 个唯一可比 BBH 模型精确复现 1,736 个，比例为 97.2%，通过 95% 门槛；MATH 仅精确复现 737/1,782，未通过，因此不得作为论文正式 C8 复现结论。

主综合能力使用 C1 官方 Average：

$$
S_i^{avg}=\frac{1}{6}\sum_{k=1}^{6}S_{ik}.
$$

数据核验已确认其与六项算术均值的最大误差约为 $1.42\times10^{-14}$。这样得到的 0–100 分具有直观解释，并能与 C6 的 `LB_Average` 直接桥接。敏感性指标为训练窗拟合的六维等权秩正态分：

$$
Z_{ik}=\Phi^{-1}\{\widehat F_{k,train}(S_{ik})\},\qquad
S_i^{bal}=100\Phi\left(\frac{1}{6}\sum_k Z_{ik}\right).
$$

验证窗和未来点只能使用训练窗经验分布函数并做尾部裁剪，禁止在全数据上重新排名造成时间泄漏。PCA 只作附加对照，不因解释方差较高就自动取代官方 Average。

### 8.6 Loss–Benchmark 桥接

C6 只有 7 条“同模型、同验证集”高可比记录，其 Loss 范围为 2.0933–2.5978、Average 范围约为 5.070–6.060；其余 68 条为不同验证集近似，完整 Loss 支持为 1.65–2.84。总体 Loss 与 Average 的 Spearman 约为 -0.549，高可比层约为 -0.607，说明方向合理但映射噪声不能忽略。

分别对 Average 与六项 Benchmark 拟合有界单调桥接。令

$$
Y_{im}=\operatorname{logit}\left(\frac{S_{im}+\epsilon}{100+2\epsilon}\right),
\qquad
Y_{im}=h_m(\log L_i)+u_{g(i)}+e_{im},
$$

其中 $h_m$ 强制不增，$u_{g(i)}$ 只对样本量足够的来源组设置收缩截距；单条来源并入 `other`，避免一个样本对应一个哑变量。候选模型为单调线性、低自由度单调样条和保序回归，按 leave-one-source-family-out 的加权误差、单调性和区间覆盖选择最简合格模型。

高可比权重为 1；中可比主权重为 0.25，并在 0.10、0.50 与剔除中可比四种口径上复核。桥接必须输出 `support_status`：`high_supported`、`expanded_supported` 或 `out_of_bridge_range`。超出 1.65–2.84 的 Loss 不作无标识外推；若为了回答题目必须给值，则仅用边界斜率受限外推并显式扩大区间。

问题三 Loss 范围约 1.914–3.527：45 条中 15 条落在高可比范围，另有 15 条仅落在 C6 扩展范围，剩余 15 条超出 C6 完整范围。每个问题三情景的 Loss bootstrap 与每个桥接 bootstrap 配对传播，输出能力的中位数、80% 和 95% 区间。三个质量成本函数是相互替代的题设情景，不是三次独立观测；问题三输出不得加入 C6 拟合。

### 8.7 动力学能力前沿

为避免把后训练收益误归为预训练规模，确认性模型只使用 `open_weight_verified` 的 pretrained/continuously pretrained 记录。将主能力分数作有界变换

$$
Y_i=\operatorname{logit}\left(\frac{S_i^{avg}+\epsilon}{100+2\epsilon}\right).
$$

逆变换固定为

$$
S_i=(100+2\epsilon)\operatorname{sigmoid}(Y_i)-\epsilon,
$$

不能误写成 $100\operatorname{sigmoid}(Y_i)$，也不能用事后裁剪掩盖不互逆。V2 在 0、5、50、99、100 五个边界/内部点上的最大往返误差小于 $10^{-10}$。

以 $\tau=0.90$ 条件分位表示开源能力前沿。月度非规模状态采用低自由度局部线性动力学：

$$
Q_{\tau}(Y_i\mid x_i,t_i,z_i)
=\beta_0+\beta_C\log_{10}C_i+\gamma^\top z_i+a_{m(i)},
$$

$$
 a_m=a_{m-1}+v_{m-1}+\eta_m,\qquad
v_m=v_{m-1}+\zeta_m.
$$

开发时用分位损失加一阶/二阶差分惩罚估计，平滑强度 $\lambda$ 与未来状态斜率的局部—全局收缩权重 $\rho$ 只由 3/6 月滚动起点验证选择。V2 选择 $\lambda=10000,\rho=0$，即数据支持高度平滑、以全局状态斜率为主的保守外推。$z_i$ 包含连续预训练标记、训练算力证据层和必要的模型族收缩截距。主模型不同时放入 $C,N,D$，避免 $C\approx6ND$ 造成机械共线。

至少拟合三套嵌套口径：

- M-C：训练算力完整样本，以 $\log C$ 表示规模，为贡献分解主候选；
- M-ND：$N,D$ 同时可得样本，以 $\log N,\log D$ 分开表示规模，作机制稳健性；
- M-N：仅参数量较完整的广覆盖诊断，不能替代题目要求的 C4 算力与数据量分析。

若 M-C 的有效样本、月份覆盖或模型族覆盖不够，仍必须报告“算力主模型不可识别”，而不能静默切换后把 M-N 冒充算力贡献。模型选择遵循滚动回测与简约原则，时间与规模交互只有在回测稳定改善且系数符号稳定时才保留。

### 8.8 规模与非规模技术贡献

选择两个具有足够样本覆盖的时点 $t_0,t_1$，并用各时点开源预训练模型的前沿规模 $x_0,x_1$。若模型含交互，用两因素 Shapley 路径平均：

$$
\Delta_{scale}=\frac12\{F(x_1,t_0)-F(x_0,t_0)
+F(x_1,t_1)-F(x_0,t_1)\},
$$

$$
\Delta_{tech}=\frac12\{F(x_0,t_1)-F(x_0,t_0)
+F(x_1,t_1)-F(x_1,t_0)\}.
$$

必须满足 $\Delta_{scale}+\Delta_{tech}=F(x_1,t_1)-F(x_0,t_0)$。贡献先在 logit 能力尺度计算；分数点贡献要把四个反事实点分别经逆 link 变换后重新做同一 Shapley 分解，不能直接对单个贡献取逆变换。两个尺度都必须闭合。仅当总变化为正且两项同号为正时报告通常意义的百分比；出现负项时报告带符号贡献、绝对贡献份额和 bootstrap 符号概率。

posttrained 层另做扩展分解，在相同基座规模和时间条件下增加 posttraining 状态项；该项称“后训练相关残余”，不并入预训练技术贡献。C3 历史 26 条只用于检验长期方向或设置弱正则化，不与 C1/C2 现代面板等权拟合。

### 8.9 算力放缓情景与 12/24 月预测

训练算力增长率只使用预测起点及其以前的 C4 开源语言模型记录，并按证据层加权。对月度前沿 $\log_{10}C$ 做稳健局部线性估计，得到近期年化增长率 $r_C$。未来算力起点是该趋势在截止月的拟合值，不是全样本无时间条件 0.90 分位；同时报告截止月原始月前沿和最近三个月中位前沿。每个 bootstrap draw 都重新抽取算力上下界、模型家族和连续月份块，并重新估计端点与增长率。预注册三种情景为：

- 延续情景：$r_C$；
- 中度放缓：$0.5r_C$；
- 强度放缓：$0.25r_C$。

若 $r_C\le0$，放缓系数不应产生反向“加速”，此时另报算力持平情景并解释数据不足。非规模状态 $a_m$ 使用最近稳定斜率并向全样本长期斜率收缩；禁止高阶多项式或无约束样条外推。分别给出预测起点后 12、24 个月的 $\tau=0.90$ 主前沿和 $\tau=0.85,0.95$ 敏感性。

能力分数最终限制在 0–100，但只有通过 link 函数自然落界，不允许预测后简单截断掩盖模型错误。由于现代同口径面板只有约 9 个月，12/24 月均属于显著外推，24 月结果必须标为 `long_horizon_extrapolation`，不能写成确定性点预测。

### 8.10 回测、不确定性与验收逻辑

滚动起点回测保证每次训练只看到预测时点之前的数据。主回测预测 3 个月和 6 个月；若历史长度允许再加入 9 个月。12/24 月无法获得同口径真实回测时，必须明确说明这是可验证性边界。评价包括 MAE、RMSE、分位数损失、80%/95% 覆盖率、区间宽度和前沿集合命中率。

不确定性采用至少 1,000 次分层块 bootstrap：以模型家族/基座为簇、连续月份为时间块，同时重采样算力测量区间、桥接来源族和问题三 Loss 样本。0.85/0.90/0.95 三条分位在同一 draw 内联合拟合并单调重排，每个分位的区间必须由自己的重排后 draw 计算。区间按估计对象拆分：历史贡献、未来前沿、问题三 Loss–Benchmark 映射分别记录，不把不同对象的区间宽度相加。

硬门禁包括：

1. C1/C2、C3、C4、C8 全部被消费并有行数、hash 和角色审计；
2. C5 与 C6 的子集关系可复现，主拟合不重复计数；
3. 预测起点以后 C4 记录进入任何训练或增速估计的数量为 0；
4. C8 至少 BBH 或 MATH hard 一项按对应官方口径达到复现门槛，另一项若失败必须 WARN 并退出正式证据；
5. 所有前沿训练样本均有开源证据层、类型、时间和匹配状态；
6. 主模型按时间回测，所有变换只在当期训练窗拟合；
7. Loss–Benchmark 各输出满足单调不增、0–100 边界和支持域标签；
8. Shapley 两项与总变化的闭合误差不超过 $10^{-10}$；
9. 问题三 45 个情景数量与 evidence 标签保持不变，且不进入历史模型拟合；
10. 同随机种子中心结果可复现，manifest 写后 hash 校验通过。

| 配比强度 | `p=p_ref,lambda_0=0` | 非零 profile 仅保留为问题二诊断 | `JOINT_P_READY=false`，不得进入问题三联合优化 |
| 质量成本 | 三种题设函数并列 | 参数 ±20% | 最优配置、Loss 与转移点区间 |
| C7 上下文 | 五个经核验离散值等权 | `eta` ±20%、strict/extended 支持域 | 上下文越长最优 Loss 不得反向降低；临界值 30000 |
| 开源口径 | C2/C4 显式 open_weight_verified | unrestricted；leaderboard_candidate 仅覆盖率敏感性 | 样本覆盖、前沿和贡献差异，缺失许可证不得默认为 unrestricted |
| 能力指标 | 官方六项 Average | 训练窗秩正态平衡分、PCA | 前沿模型集合、贡献和预测变化；验证窗不得重排 |
| 桥接权重 | 高 1、中 0.25 | 中 0.1/0.5、仅高可比 | 单调方向、留来源族误差、支持域、覆盖率和预测区间 |
| 前沿分位 | 0.90 | 0.85、0.95 | 贡献和预测区间 |

统一检查包括：所有约束回代、预测物理边界、残差异方差、异常点影响、参数 bootstrap、训练支持域距离、随机种子复现和单位换算。任何依赖估算或半合成数据的结论均单独标注。

## 11. 外部资料核验

- [SlimPajama Meta-rater 数据卡](https://huggingface.co/datasets/opendatalab/SlimPajama-Meta-rater/blob/main/README.md)：核实 22 个字段的语义、二分类 logits 顺序、PRRC 六级 logits 与官方 argmax 处理建议。

- [Scheffé 混料实验](https://academic.oup.com/jrsssb/article/20/2/344/7027344)：单纯形约束下混料响应面的理论依据。
- [Aitchison 组成数据分析](https://academic.oup.com/jrsssb/article/44/2/139/7027742)：解释和为 1 的组成数据依赖及对数比方法。
- [CRITIC 客观赋权](https://www.sciencedirect.com/science/article/pii/030505489400059H)：基于指标变异与相关冲突确定权重的理论来源。
- [Pythia 官方仓库](https://github.com/EleutherAI/pythia)：核实 8 个主模型规模、共同数据顺序和多检查点训练轨迹的设计。
