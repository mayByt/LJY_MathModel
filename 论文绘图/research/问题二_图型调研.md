# 问题二：广义标度律的图型调研

本文件是讨论稿，不是正式成图清单。已读取题目原文、原始附件、当前结果与源代码；没有查看项目已有图片的视觉内容，也不沿用已有图型清单。建议以 `问题二/results_p12_final_v2/` 为讨论基准。颜色遵照用户已指定的柔绿森林色板，交由公共配置统一管理。

## 1. 本问必须回答什么

原题位于 `../中文题目/F题/算力约束下提升大语言模型能力的资源配置建模.docx`，问题二及附录 A 要求：

1. 用 B1 拟合经典参数—数据标度律，结合问题一输出的质量与领域配比，构造包含 N、D、Q、p 的广义标度律。
2. 说明附件 A、B 相互独立时的跨体系连接假设；若 Q=1 退化为经典形式，应说明根据。
3. 分析 N、D、Q 的边际效用、弹性及数据领域的替代/互补关系。
4. 推导质量提高 0.1 与参数扩张等价的条件，完成参数估计、检验、验证。
5. B2 或 B3 至少一种用于族外/插值验证，B4 与 B5 用于跨族/文献验证；B6/B7/B8 用于质量分析；结合 B9/B10 讨论大规模外推。

**原题特别明确：B6–B8 均为基于真实数据校准的半合成补充集，不能称为直接实验观测。** 问题二从问题一的冻结接口引入附件 A 信息，不重复读取 A 原始文件进行拟合。

因此本问的主图叙事应是“证据覆盖 → 经典规律 → 质量增益 → 资源替代 → 配比与外推边界”。不宜把图全部集中在拟合好不好，也不能把半合成网格与真实训练检查点画成同一种证据。

## 3. 关键结果及解释边界

### 经典标度律

获选 M0：`L0=E+A·n^(−α)+B·d^(−β)`，其中 n=N/10^9、d=D/10^9；E=1.68979756，A=0.35398032，B=1.24030558，α=0.33997658，β=0.27987813。留一规模平均 RMSE：M0=0.000146888，MC=0.084909891，MND=0.000147581。M0 与 MND 近乎重合，正式图不应通过窄轴夸大二者差异。

`classic_scaling_bootstrap.csv.gz` 共500次，484次有效，16次因独立规模簇太少失败。α的有效抽样95%分位区间为[0.33985717,0.34010087]，β为[0.27981884,0.27993045]。这些极窄区间仅刻画当前 B1 数据与拟合设定下的重采样稳定性，不能解释为跨模型族常数已精确确定。删除 D<2 的32个检查点后，参数最大相对变化约0.052965%。

### 质量修正

GQ2：`ΔQ=cQ(1−Q)^νQ`，cQ=0.36203993，νQ=0.99028807。四类切分等权（各0.25）的选模 RMSE=0.07195937；GQ1=0.11730898、GQ3=0.07438186、GQ4=0.08383123。GQ2质量参数500次 bootstrap 全有效，cQ 的95%分位区间[0.33270611,0.39225322]，νQ为[0.91805022,1.06813313]。其质量带应明确“固定经典参数、按 N,D 单元重采样”。

**现稿须更正的统计表达：** 0.07195937 是四类切分家族等权得分，不是69个留出块等权均值。后者在 `cv_summary` 中为0.07020271。选模图必须沿用前者，逐折点只作辅助，不能把数量最多的45个 leave_cell 折默认为更重要。

### 质量的资源等价与配比

参考点 N=1B、D=150B、Qref=0.5389559588、sQ=1、固定 pref 时，ΔQ=0.1 对应参数相对增幅37.2985%、Token相对增幅56.9474%。这属于模型性能等价，尚未包含提质成本，因此不能标“节省37.3%成本”。同一问题在sQ={0.5,1,1.5}情景下会明显变化，高质量区域映射截断还会导致饱和。

17域共136个二阶对，bootstrap分类为75组互补、61组不确定，没有被稳定识别的替代关系。`R(pstar)` 点估计−2.289763，95%区间[−3.568433,0.113031]跨0；pstar只能做敏感性，不应在图中标为稳定优胜方案。1B迁移综合相关0.734158，保留方向信息，不能宣称精确强度迁移。

非零配比情景486行中52行预测低于E，最低1.047781；联合配比接口 `JOINT_P_READY=false`，固定pref主接口可用。**`mixture_strength_profile` 是无量纲预设倍数，λ0=profile×0.482225。** profile=0.5/1对应λ0=0.2411125/0.482225，不能把0.5/1直接标成有Loss量纲的λ0。当前论文对此存在符号混用，应在图和图注同步纠正。

### 不确定性不可混池

`generalized_scaling_bootstrap.csv.gz` 的500行混合了3个sQ（167/167/166行）、4个配比强度（各125行）及2类配比来源（各250行）。整表分位数是混合情景分布，**不是固定主情景的95%置信区间**。画主模型区间时优先用已经验证抽样单位的经典/质量参数抽样；需要含跨层不确定性的固定情景区间时，须按同一情景重新评估冻结抽样，不新增伪 bootstrap。

## 4. 图型选择的文献依据

- [Hoffmann 等：Training Compute-Optimal Large Language Models](https://arxiv.org/html/2203.15556v1)，图3使用等算力剖面定位谷值，图4将参数拟合等高线与等算力切片对应起来。本问可借鉴“观测点—连续模型—资源等价线”的表达，不能把模型插值节点伪装成训练点。
- [Kaplan 等：Scaling Laws for Neural Language Models](https://arxiv.org/abs/2001.08361)研究跨量级幂律关系，支持对N、D使用对数尺度，以及对可约损失作机制变换检查。这里采用当前数据自己拟合的系数，不移植文献数值。
- [Goyal 等：Scaling Laws for Data Filtering，CVPR 2024](https://openaccess.thecvf.com/content/CVPR2024/papers/Goyal_Scaling_Laws_for_Data_Filtering--_Data_Curation_cannot_be_Compute_CVPR_2024_paper.pdf)研究数据质量与计算规模的关系。检索摘要可核实其主题，但本次完整PDF抓取返回403，因此不以未核实的具体图号或配色作为依据。

下面方案由本项目的数据形状和论证需要推导，不把更换颜色或互换横纵轴计作新方案。
