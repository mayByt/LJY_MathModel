# 配色与版式结论

## 已确定的颜色

按用户在本轮提供的“柔绿森林”图片底部 HEX 原样转录，**颜色已确定，不再待选**。原参考存于 `references/用户指定_柔绿森林.jpg`。该图片是用户选定的视觉参考，不能称 Nature 官方色板。

|色名|HEX|建议作用|
|---|---|---|
|嫩绿|`#B8DBB3`|浅填充、区间层；不作白底细线|
|叶绿|`#86BC79`|质量 Q 与提质投入|
|松绿|`#71A682`|数据量 D、质量分布主色|
|雾青|`#81989B`|基线、次要结果|
|赭金|`#D19246`|上下文注意力开销、必要对照|
|草灰|`#B5AF8B`|辅助类别的面积填充，避免与叶绿成唯一对照|
|蓝灰|`#7EA4B6`|参数规模 N、规模关联贡献|
|靛紫|`#4A4F7E`|主模型、训练成本、重点结果|

同一问内固定语义，跨问出现 N/D/Q 等相同对象也保留颜色。色板不是要求每张图把8色都用满：通常2–4个类别色足够；17个领域用轴标签和单色强度，避免8色循环造成误认。

四问侧重分别是：Q1松绿与叶绿；Q2靛紫与蓝灰；Q3靛紫训练、叶绿提质、赭金注意力；Q4靛紫/蓝灰/松绿表示三档增速，蓝灰/赭金表示规模/非规模贡献。正负量全篇采用靛紫—白—赭金、零值居中；配色只表示数学正负，不暗示正值必然更好。

配色、描边、字体、尺寸、导出参数写在 `../config/style.json`。深色描边由原色同色相派生，嫩绿借用叶绿深线；白色背景和近黑正文是中性排版色。

## 实测可读性

已运行指定 skill 的 `palette_tool.py`（结果见 `色板可读性检查.txt`）：

- 正常视觉下雾青/蓝灰最小 ΔE00≈7.3；绿色盲模拟下叶绿/草灰≈3.5；两者不能作为仅靠颜色区分的关键线条。
- 叶绿/草灰明度几乎相同，黑白打印尤其需要标记、线型或直接标签。
- 嫩绿默认加深后的白底对比度仍只有2.26:1，因此不用作独立细线；配置改用叶绿深线，白底对比度约3.82:1。
- 每张图只取任务需要的子集，点图用圆/方/三角，曲线用实/虚/点划；区间用宽度和线宽区分。这是保留指定审美同时改善辨认的方法，不能宣称原8色整套天然色盲无障碍。
- 顺序色图由用户色板的浅→深锚点构成，正式图须检查明度单调；称“项目自定义渐变”，不冒称 Crameri 的感知均匀科学色图。

## 期刊与论文调研：采纳什么

1. [Nature 官方图形指南](https://research-figure-guide.nature.com/figures/preparing-figures-our-specifications/)强调轴与单位、可读文字、可访问颜色、避免装饰与文字重叠。采用这些信息设计原则。其常用字体为Arial/Helvetica；本项目按用户明确要求采用宋体与Times New Roman，不将本项目设置宣传为Nature排版规范。
2. [Crameri 等，Nature Communications 2020](https://www.nature.com/articles/s41467-020-19160-7)讨论不适合的色图如何造成视觉失真。采用“连续量看明度、正负量零点居中、不用jet”的原则；不把离散色板简单拉伸成分类与数值混杂的色条。
3. [Paul Tol 原作者说明](https://sronpersonalpages.nl/~pault/)展示了灰度、高对比与浅底配深线的区别。借鉴“浅色填充、深色线条、冗余编码”的办法；用户已给定配色，因此没有替换为Tol色板。
4. [ggsci 原作者的NPG文档](https://nanx.me/ggsci/reference/pal_npg.html)及[源码](https://raw.githubusercontent.com/nanxstats/ggsci/master/R/palettes.R)明确NPG是受到Nature Reviews Cancer启发的色板。调研时核验过，但现行配置遵循用户色板。论文/会议不存在必须照抄的一套通用“顶刊HEX”。

## 字体、尺寸与图内信息

- **中文宋体 SimSun；英文与数字 Times New Roman；公式 STIX。** 已验证本机字体路径、中英混排无缺字，测试PDF嵌入两种字体且无Type 3，详见 `字体与环境检查.txt`。
- 当前论文A4左右边距22.5 mm，版心165 mm。建议通栏160 mm，双面板各78 mm、中缝4 mm；2–3个面板内保持共同边距、基线和图例区。
- 最终尺寸下轴标签9 pt、刻度与图例8 pt、面板字母10 pt、必要注释最低7 pt。不能先画大图再随意缩到半栏；绘制时直接用最终毫米尺寸。
- 图内保留坐标、单位、色条、必要图例、面板字母和少量核心数字。解释、拟合前提、样本选法、区间性质放在图注，不放长标题或文字段落。
- 数据点、模型曲线、估算外推要有不同标记/线型；缺失、失败、0值分开。图区默认白底，去掉上右边框，网格按需轻量使用。
- 正式图一张一文件，计划输出300 dpi PNG与字体嵌入的矢量PDF。组合图仅合并同一论证中单位/坐标兼容的2–3个面板；本次尚未批量制作正式图。
