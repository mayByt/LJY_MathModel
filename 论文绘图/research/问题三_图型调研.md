# 问题三：算力约束下的资源配置与结构转移——图型调研

调研阶段：只读题目、原始附件、计算代码、结果表与论文章节，未打开或参考项目已有图像。以下是供讨论的候选，不是最终制图清单。配色按用户给定的柔绿森林色板交由公共配置管理；本文件不另设色板。

## 先说明三个会影响图注的事实

1. **主结果可作为绘图输入，但严格域不是全部成功。** `results_v1` 的 8/8 个上游输入、19/19 个登记输出，当前文件 SHA-256 均与 manifest 一致。主扩展域 45 个情景全部求解成功；严格域 45 个情景中，33 个成功、3 个明确预算不可行、9 个虽然留下数值但求解器失败。这 9 条不得作为“严格域最优解”进入对比曲线。
2. **`joint_observed` 只核验 N、D，不代表质量也在观测支持内。** `src/problem3/optimize.py:classify_support` 仅比较 N、D 边界。主结果中 15 条中预算情景带此标签，但其质量均约为 0.999999，超过配置设定的经验质量上界 0.880183。图注宜写“N–D 共同支持，质量取模型上界”，不能写“全部维度实测支持”。
3. **不确定性有两套计算口径。** 锚点使用 500 组联合参数抽样，对每组的 45 个情景重优化；转移分析从这 500 组中按标准化参数第一主成分分层选取 200 组，并采用 `registered_local_lattice` 局部格点近似搜索。转移概率是该算法和模型下的出现比例，不是独立训练实验的频率，也不是严格全局求解的概率。

## 1. 题目要求与推荐论证顺序

题目原文：`../中文题目/F题/算力约束下提升大语言模型能力的资源配置建模.docx`，问题三及附录 A/B。已用 ZIP/XML 读取题目文本，公式单位另外与配置及计算代码核对。

题目必须回答：

- 在总预算内配置参数量 N、训练 Token 数 D、质量 Q，并说明是否联立优化 17 域配比 p。
- 比较指数、幂函数、对数三类质量成本的配置差异，至少跨三个预算量级。
- 给“结构性转移”明确的数学定义，并从连续预算路径识别其发生位置。
- 上下文长度外生给定，取值须来自 C7；解析给出注意力成本与训练成本相等的临界长度，并对真实可行长度做敏感性分析。

本问最适合的叙事是：**真实上下文档位 → 预算约束与机会成本 → 低预算下三种不同质量状态 → 最优配置随预算变化 → 转移位置与条件不确定性 → 外推及假设敏感性**。只画三档均值柱无法证明结构转移。

## 3. 结果特征与图形选择依据

### 3.1 低预算存在三种清晰而不同的质量状态

下表来自 `optimal_allocations.csv` 中 4096 上下文、主扩展域、最低预算的记录：

|质量成本|N / B|D / B Token|Q_A|预测 Loss|质量成本份额|
|---|---:|---:|---:|---:|---:|
|exponential|0.259187|4.821008|0.671056|3.168981|14.7913%|
|power|0.215205|6.814204|0.538956|3.179619|0.0000%|
|logarithmic|0.337313|2.952758|0.999999|3.118051|32.0805%|

幂函数停留基线、指数取内点、对数达质量上界，是本问最鲜明的结果特征。对数成本的 Loss 最低只说明题设指定成本下的条件结果，不能由此宣称真实提质过程应采用对数成本。中、高预算大多数 Q 达到边界；质量分布有明显点质量，不能用平滑小提琴把边界点伪造成连续分布。

### 3.2 上下文临界是解析成本关系

`C_attention/C_train = eta × L_ctx / 6`，故临界长度 `6/eta=30000`。该比值与预算、N、D、Q 都无关。五档上下文中 32768、131072 位于临界线以上。它是外生上下文的成本临界，不是预算路径上的结构转移；不与质量启动/饱和事件混进同一概率图。

### 3.3 预算路径上的结构变化有明确事件口径

61 个预算点覆盖 10^19–10^24 FLOPs，当前共有 37 个中心事件（主要 13、次要 24）。出现概率范围 0.795–1.000，均超过登记阈值 0.70。主要转移的中心夹逼宽度最大为 0.005208 个 log10 预算单位；这不是参数 bootstrap 置信区间。对数情景在当前预算起点已经到质量上界，事件表没有新质量转移，不能画成“无结构”或“概率为零”。

次要断点按照 BIC 改善≥10、斜率差绝对值≥0.15 筛选。检查发现 `secondary_breakpoint()` 当前在整条路径拟合分段直线，并没有先按 `active_set` 分段；论文“活跃集合不变区段”的表述比实现更强。绘图应先称“配置斜率断点”，不额外声称它与主要转移完全独立。

### 3.4 领域配比没有随预算迁移

所有领域 Token 都按 `D_i=p_ref_i D` 缩放。适合画绝对领域 Token 的区间/数量排序，不适合画暗示领域比例演变的冲积图、配比相变或领域竞争网络。三类资源的成本份额是真正会变的组成量，可用堆叠面积；固定上下文时训练与注意力的份额比固定，三元轨迹必然沿固定射线，不能把它包装成三个自由权衡维度。

## 6. 外部图形研究与适用结论

本次查到与问题三最贴合的正式一手论文是 [Hoffmann 等，NeurIPS 2022，Training Compute-Optimal Large Language Models](https://proceedings.neurips.cc/paper_files/paper/2022/file/c1e2faff6f588870935f114ebe04a3e5-Paper-Conference.pdf)。论文用等算力损失剖面和最优规模路径表达资源取舍，支持本项目采用 Q3-05/Q3-06/Q3-07 的编码方向。我们增加质量轴与活跃约束状态，所有数值取自本项目冻结模型；不将论文训练观测与本项目模型曲面混称实测。

[Kaplan 等，Scaling Laws for Neural Language Models](https://arxiv.org/abs/2001.08361) 的一手研究聚焦损失与规模、数据和计算量的跨数量级规律；本问预算跨度5个数量级，因此预算与N/D图使用对数轴有直接数据依据。各预算点不等间隔的原始线性坐标会把低预算转移挤到一侧。

本问的新颖性应来自“离散上下文真实支持、约束状态转移、数值区间与参数区间分开、边界点质量显式展示”，不是用雷达、装饰3D或固定配比冲积图追求复杂度。外部论文只用于图形论证思路；配色遵守用户指定方案，由主调研统一配置和检查。
