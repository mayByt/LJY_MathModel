# 问题一绘图

在 `论文绘图` 目录运行。此包只读取正式结果；质量明细在隔离缓存恢复，不写回原结果目录。

```bash
.venv/bin/python -m q1.prepare_quality
.venv/bin/python -m q1.run --id Q1-09
.venv/bin/python -m q1.describe
```

- `prepare_quality` 按问题一原配置全量读取 A1–A3，以 seed=2026、500次 bootstrap 运行原质量评分函数；不反序列化 pickle。数据根目录采用公共 `config.RAW`，可由 `PAPER_FIGURE_RAW` 指定。
- 重建缓存包括原始词数、样本/指标/语义块评分、权重与其他原程序质量导出。先比较7域质量及CI与冻结汇总，显式容差1e-6；本次最大差1.233e-7，原/当前数值库版本存于 `cache/q1_quality/verification.json`。
- `run` 一次只画一个编号。优先列表为02、08、09、10、11、13、17、19、20、23、25、27、28、05、06、07、15、16、18、22。没有批量跳过逐张审阅的模式。
- 每图保存 PNG、PDF、统计JSON，并生成公共 review_queue 项。生成后立即提交专门审阅者；重画后原哈希的通过记录失效。
- `describe` 从当前20张图的统计JSON生成图注、数值解读和说明，不触碰图像；它可以在审阅完成后更新审阅状态。

部分版式经实际数据调整：Q1-06采用分组权重条图以保持22标签可读；Q1-28按目标值展示30起点解簇，不放大约1e-11的支持约束数值残差。Q1-25只展示固定14域的三域条件切片，绝不视为17维全局最优的证明。60M/1B绝对Loss校准、推断域回退、近优配方bootstrap的条件均写在逐图说明中。
